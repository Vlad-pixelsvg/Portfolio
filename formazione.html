Manuale Operativo MetsGeneratore

Procedura standard per la preparazione dell'ambiente, l'estrazione dei record catalografici (Clavis, Sebina, SBN), la generazione dei pacchetti METS/MODS/MIX e la verifica strutturale.

Fasi del Flusso

  1. 01 Struttura cartelle e Static
  2. 02 Estrazione da OPAC / SBN
  3. 03 Posizionamento file estratti
  4. 04 Come si presenta lo Static
  5. 05 Generazione e Controllo
  6. 06 Modifica manuale XML
FASE 01

Impostazione delle cartelle e posizione di static

Per funzionare correttamente in locale senza errori di percorso, l'eseguibile MetsGeneratore.exe deve trovarsi nella stessa directory radice della cartella static (che contiene l'interfaccia web del visualizzatore Flask e gli asset).

📁 Cartella_Lavoro_METS/
├── ⚙️ MetsGeneratore.exe <-- Eseguibile principale
├── 📁 static/ <-- OBBLIGATORIO: deve stare accanto all'eseguibile
│ ├── 📁 css/
│ ├── 📁 js/
│ └── 📁 img/
├── 📁 templates/ <-- Template HTML dell'interfaccia di controllo
└── 📁 Lotti_Da_Elaborare/ <-- Cartella con le sottocartelle dei volumi scansionati
├── 📁 [BID_o_ID_Volume_1]/
└── 📁 [BID_o_ID_Volume_2]/
Attenzione: Non spostare o rinominare static

Se avvii MetsGeneratore.exe da una cartella in cui non è presente static accanto ad esso, l'interfaccia grafica di controllo si aprirà senza fogli di stile e senza pulsanti funzionanti. Non avviare mai il programma direttamente dentro un file .zip: estrai sempre tutto il pacchetto prima.

FASE 02

Estrapolazione dei metadati da Clavis, Sebina o SBN

Il software legge automaticamente tutti i file .txt e .mrc presenti nella cartella di input per abbinare i metadati bibliografici alle immagini tramite identificativo (BID / ID). A seconda del gestionale utilizzato, procedi come segue:

A. Estrazione da Clavis

  1. Accedi al catalogo gestionale Clavis e ricerca l'opera tramite titolo o BID.
  2. Apri la scheda bibliografica completa e seleziona la funzione di Esportazione / Download record.
  3. Scegli il formato UNIMARC (.mrc) oppure esportazione testuale strutturata (.txt).

B. Estrazione da Sebina / Polo SBN

  1. Individua la notizia bibliografica sul catalogo Sebina o sull'OPAC SBN.
  2. Assicurati che sia visibile il codice BID univoco della notizia (es. IT\ICCU\TO0\...).
  3. Esporta il tracciato in formato ISO 2709 / UNIMARC (.mrc) o salva la visualizzazione completa in formato Testo (.txt).
FASE 03

Dove inserire i file estratti e nomenclatura immagini

I file bibliografici esportati (.mrc e/o .txt) vanno inseriti nella cartella contenente i lotti da processare (o nella cartella specificata all'avvio del programma). Il motore legge tutti i file .txt e .mrc insieme: puoi quindi avere un unico file cumulativo per l'intero lotto oppure un file per ogni singolo volume.

📁 Lotto_Biblioteca_X/
├── 📄 export_clavis.mrc <-- File esportato dal gestionale (qui o nelle sottocartelle)
├── 📄 export_sbn.txt <-- Eventuale secondo export testuale
├── 📁 TO00123456/ <-- Cartella nominata con il BID dell'opera
│ ├── 🖼️ TO00123456_0001_copertina.tif
│ ├── 🖼️ TO00123456_0002_guardia.tif
│ ├── 🖼️ TO00123456_0003_frontespizio.tif
│ └── 🖼️ TO00123456_0004.tif
└── 📁 TO00987654/

Parole chiave riconosciute automaticamente nei nomi file

Durante la scansione e la rinomina, inserisci le seguenti parole chiave nel nome del file immagine affinché il generatore compili automaticamente la mappa strutturale (structMap) del METS:

Parola chiave nel filename Etichetta / Tipo attribuito nel METS Esempio pratico
copertina Copertina (anteriore / posteriore) BID_0001_copertina.tif
dorso Dorso del volume BID_0002_dorso.tif
guardia Carta di guardia BID_0003_guardia.tif
frontespizio Frontespizio BID_0005_frontespizio.tif
(nessuna parola chiave) Pagina numerata progressiva BID_0006.tif
FASE 04

Come si presenta l'interfaccia static (Visualizzatore)

Avviando MetsGeneratore.exe, viene avviato un server locale e si apre automaticamente nel browser l'interfaccia web basata sulla cartella static. Questa dashboard permette di selezionare il percorso di lavoro, lanciare l'elaborazione batch e ispezionare visivamente il risultato prima della consegna.

  • Barra superiore / Selezione cartella: permette di indicare la directory madre contenente le cartelle dei volumi e i file .mrc/.txt.
  • Pannello di avanzamento e log: mostra in tempo reale quali BID sono stati agganciati ai metadati e segnala eventuali cartelle prive di corrispondenza catalografica.
  • Anteprima struttura e immagini: consente di sfogliare le pagine riconosicute (copertina, frontespizio, tavole) affiancate ai metadati MODS estratti e ai parametri tecnici MIX (risoluzione DPI, spazio colore, dimensione).
FASE 05

Come generare i pacchetti e fare il controllo qualità

  1. Verifica che nella cartella selezionata siano presenti sia le sottocartelle immagini sia i file .mrc/.txt.
  2. Clicca su Avvia Generazione METS nell'interfaccia. Attendi il completamento dell'analisi delle immagini (calcolo hash MD5/SHA e lettura header TIFF/JPEG per la sezione MIX).
  3. Al termine, all'interno di ogni cartella volume verrà creato il file [BID]_mets.xml (o mets.xml).

Checklist obbligatoria di controllo

Prima di considerare chiuso un lotto, verifica sempre questi 4 punti nell'interfaccia di controllo:

  • Corrispondenza Titolo/Autore (MODS): il titolo mostrato nell'anteprima corrisponde effettivamente al frontespizio scansionato (nessun scambio di BID).
  • Conteggio file (fileSec): il numero totale di file elencati nel METS coincide esattamente con il numero di immagini presenti nella cartella (esclusi file di sistema come Thumbs.db).
  • Sequenza logica (structMap): copertina, guardia e frontespizio sono nell'ordine corretto e non ci sono pagine invertite.
  • Dati tecnici (MIX): i DPI rilevati (es. 200 o 300 DPI) e le dimensioni in pixel sono coerenti con le specifiche di progetto.
FASE 06

Come modificare il file XML manualmente in caso di necessità

Può capitare che un record catalografico sia incompleto (es. manca la data di pubblicazione, l'autore è scritto in modo errato su SBN, oppure bisogna correggere l'etichetta di una singola pagina). In questi casi non serve rigenerare tutto: puoi intervenire direttamente sul file .xml.

Regola fondamentale per l'editing XML

Apri il file esclusivamente con Visual Studio Code o Notepad++ (mai con Word o WordPad). Assicurati che la codifica in basso a destra sia impostata su UTF-8 e non toccare mai i codici CHECKSUM (MD5) a meno che tu non abbia sostituito l'immagine.

1. Correggere Titolo, Autore o Data (Sezione <mods:mods>)

Cerca nel file il blocco <mods:titleInfo>, <mods:name> o <mods:originInfo> e modifica solo il testo contenuto tra i tag di apertura e chiusura:

Esempio sezione MODS nel file METS 
<mods:titleInfo>
    <!-- Modifica solo il testo interno se il titolo su SBN ha refusi -->
    <mods:title>Storia della Città di Torino</mods:title>
</mods:titleInfo>

<mods:originInfo>
    <mods:place>
        <mods:placeTerm type="text">Torino</mods:placeTerm>
    </mods:place>
    <!-- Inserisci l'anno se mancante nel record originario -->
    <mods:dateIssued>1898</mods:dateIssued>
</mods:originInfo>

2. Correggere l'etichetta di una pagina (Sezione <mets:structMap>)

Se hai dimenticato di scrivere frontespizio nel nome del file prima della generazione, scorri fino in fondo all'XML nella sezione <mets:structMap> e modifica l'attributo LABEL del relativo <mets:div>:

Esempio sezione structMap nel file METS 
<mets:div ID="DIV_0003" ORDER="3" TYPE="page" LABEL="Frontespizio">
    <mets:fptr FILEID="FILE_0003" />
</mets:div>

Risoluzione rapida problemi comuni

Il file XML dà errore quando lo riapro nel browser dopo una modifica
Hai inserito un carattere speciale non ammesso in XML oppure hai cancellato per sbaglio una parentesi angolare (< o >). In XML i caratteri &, < e > dentro i testi devono essere scritti rispettivamente come &amp;, &lt; e &gt;.
Il generatore non trova i metadati per una cartella anche se ho messo il file .mrc
Verifica che il nome della cartella delle immagini corrisponda esattamente al BID contenuto nel record esportato (senza spazi extra o caratteri non validi come \ o / al posto dell'underscore).
