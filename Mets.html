Cos'è e a cosa serve in parole semplici

Non serve essere programmatori per capire il valore di MetsGeneratore.py nelle campagne di digitalizzazione.

1. La "Colla Digitale" del Libro

Immagina di aver digitalizzato un libro antico: hai da una parte la **scheda del catalogo** (con autore, titolo e anno) e dall'altra **decine di foto TIFF** delle pagine.

MetsGeneratore.py agisce come un registro automatico: "incolla" i dati del catalogo con le singole immagini nell'ordine esatto di lettura.

Connette Dati & Immagini

2. Cosa serve per usarlo?

Solo tre elementi fondamentali già presenti nei tuoi progetti:

  • File XML dal catalogo: esportato da Clavis NG, SBN o altro software catalografico.
  • Cartella Immagini: i master TIFF scansionati dallo scanner planetario.
  • l'Eseguibile installato su un qualsiasi PC dell'istituto.
Requisiti minimi standard

3. Cosa ottieni alla fine?

Un unico pacchetto standardizzato (**METS/XML**) contenente:

  • • Scheda del libro traducibile in tutti i portali internazionali.
  • • Impronta digitale (MD5) di ogni foto per evitare alterazioni.
  • • Dati tecnici dello scanner (DPI, colori, risoluzione).
  • • L'ordine sequenziale per sfogliare il libro online.
Pronto per l'invio o l'archiviazione!

Sfida & Soluzione Tecnologica

Panoramica del Progetto

Automatizzare la convergenza tra catalogo bibliografico e metadati di conservazione hardware.

Il Problema nelle Campagne MAB

L'Integrazione Difficile tra Metadati Catalografici e Hardware di Scansione

Nelle campagne di digitalizzazione di fondi librari, coordinare i dati di catalogo con gigabyte di master TIFF ad alta risoluzione richiede tradizionalmente enorme lavoro manuale. Senza automazione, l'incongruenza nei checksum MD5 o la perdita dei metadati EXIF rende i dati inutilizzabili nei depositi digitali a lungo termine.

SOLUZIONE AUTOMATIZZATA
• Mappatura Catalogo UNIMARC → MODS
• Metadati Hardware TIFF EXIF → MIX
• Integrità File MD5 Hash Block
• Standard Output METS XML 1.12
01

Parsing SBN / Clavis

Parsing intelligente di dump XML proveniente dai software di catalogazione. Estrazione automatica dei campi UNIMARC.

02

Mapping MODS

Conversione dei tag UNIMARC (Titolo, Autore, Edizione, Note) nello schema descrittivo internazionale MODS.

03

Analisi TIFF & MD5

Ispezione delle immagini master: estrazione DPI, risoluzione, profili colore e calcolo checksum di sicurezza MD5.

04

Generazione METS

Assemblaggio finale dell'albero METS XML con fileSec, structMap paginata e validazione automatica.

Caratteristiche Principali

Progettato per garantire accuratezza catalografica, efficienza di processo ed aderenza agli standard W3C e Library of Congress.

Parsing UNIMARC & Clavis XML

Riconoscimento ed estrazione automatica dei tag catalografici chiave: Tag 001 (BID/Barcode), 200 (Titolo), 210 (Edizione), 215 (Descrizione fisica), 300 (Note) e 700 (Autori).

UNIMARC / MARC21 Supportato

Metadati Tecnici NISO Z39.87

Lettura automatica dell'header delle immagini master tramite schema MIX: registra modello scanner, profondità di bit, profilo colore e risoluzione ottica X/Y.

Schema MIX / EXIF Automatico

Integrità Checksum MD5

Calcolo dinamico degli hash per la conservazione a lungo termine. Elaborazione a blocchi di memoria (chunking) per gestire file TIFF senza saturare la RAM.

Elaborazione Batch Massiva

Associazione automatica tra cartelle contenenti le scansioni e gli ID di catalogo (BID/Barcode), consentendo la generazione di centinaia di METS in un solo ciclo.
