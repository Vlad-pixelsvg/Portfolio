MetsGeneratore.py

Pipeline di Generazione METS/XML per la Digitalizzazione Libraria

Tool Python per la creazione automatizzata di pacchetti di archiviazione digitale (METS / MODS / MIX) tramite parsing di dati catalografici UNIMARC ed estrazione automatica dei metadati tecnici EXIF/TIFF.

Ma a cosa serve?

Non tutte le biblioteche e gli enti dispongono di software di metadazione avanzati o di complessi sistemi di archiviazione digitale come DSpace o Obsidian.

È invece molto comune possedere uno spazio di digitalizzazione dotato di scanner a lampada, apparecchiature da ufficio o piccoli planetari. È proprio qui che nasce l'esigenza concreta di inviare i propri materiali digitalizzati ad altri enti, archivi centrali o aziende esterne garantendo un sistema di metadazione internazionale perfettamente conforme alle norme vigenti (METS / XML).

Questo programma permette di prendere la cartella del libro digitalizzato e l'estrazione del volume catalogato (dal proprio gestionale per la massima precisione o dal catalogo nazionale per un XML generico) e creare, con un semplice click, un file XML valido e strutturato all'interno di ciascuna cartella.

Di cosa hai bisogno per iniziare

1

Scansioni Immagini

La cartella con le immagini digitalizzate del volume (es. file TIFF o JPEG con le pagine del libro).

2

Dati Catalografici

L'esportazione XML del catalogo dal gestionale (es. Clavis NG o SBN) oppure un XML scaricato dal catalogo nazionale.

3

Lo Script Python

Il file MetsGeneratore.py pronto all'uso sul tuo computer (richiede Python installato).

Cosa ottieni come risultato

Un file "mets.xml" dentro ogni cartella

Il programma crea automaticamente un documento XML standard all'interno di ciascuna cartella del libro digitalizzato.

Pronto per l'invio e la conservazione a lungo termine

Il pacchetto prodotto è conforme agli standard internazionali della Library of Congress e pronto per essere consegnato ad altri enti o caricato in un archivio digitale.

Caratteristiche Tecniche

Funzionalità avanzate per la gestione professionale delle campagne di digitalizzazione.

Parsing UNIMARC & Clavis

Mappatura automatica dei tag catalogati (001, 200, 210, 215, 300, 700) per convertire le informazioni bibliografiche nello standard MODS.

Metadati Tecnici (MIX)

Lettura degli header hardware TIFF via Pillow (risoluzione, dati del sensore, spazio colore) ed esportazione nello schema NISO Z39.87 / MIX.

Impronta Digitale MD5

Calcolo dinamico a blocchi dell'hash MD5 per ogni singola immagine. Garantisce l'integrità del file per la conservazione sostitutiva.

Elaborazione Massiva

Processa interi lotti di lavoro collegando automaticamente ogni cartella di immagini al rispettivo codice identificativo (BID o Barcode).

Standard Library of Congress

Generazione rigorosa conforme agli schemi W3C con corretta definizione dei namespace (mets, mods, mix, xlink).

Esecuzione Semplice

Nessun software pesante da installare. Lo script può essere avviato da riga di comando o integrato in procedure automatiche.
